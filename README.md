# FreeGPT

Unrestricted AI chatbot. Runs on GitHub Pages.

## Setup

### 1. API Key (free)
- Go to https://api.together.xyz
- Sign up → get free API key
- $25 free credits on signup

### 2. Upload to GitHub
- New repo → upload this zip contents
- Make repo **public**

### 3. Enable GitHub Pages
- Repo → Settings → Pages
- Source: **GitHub Actions**
- Save

### 4. Done
- GitHub Actions will auto-deploy
- Your URL: `https://yourusername.github.io/reponame`
- Open site → Settings → paste API key → ask anything
